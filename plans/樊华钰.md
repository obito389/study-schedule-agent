# 樊华钰 Implementation Plan（前端）

> 按 README 要求建立个人计划，与熊翔的 `planning.md` 对齐。
> 对齐方向：熊翔 → 樊华钰：状态枚举、动作预览、回执和用户事实。
> 完成标准：前端状态与后端返回一一对应。

## Goal

在五周内交付可运行、可演示的前端：Vue 3 + TypeScript + Vite + Element Plus + FullCalendar。
覆盖日程日历、动作预览确认、版本冲突处理、撤销和用户事实管理。

## Tech Stack

- Vue 3（组合式 API）、TypeScript、Vite
- Element Plus（表单/表格/弹窗/反馈）
- FullCalendar（日程与时间块展示）
- Axios（调用 `/api/v1/...`）
- dayjs（时间格式化）

## 验收方法

1. 在 `frontend/` 执行 `npm install`。
2. 执行 `npm run type-check`（即 `vue-tsc --noEmit`），无类型错误。
3. 执行 `npm run build`，产物输出到 `dist/`。
4. 执行 `npm run dev`，打开 `http://localhost:5173`：
   - 日历页显示课程块和待排任务；
   - 输入指令后弹出动作预览，状态为"待确认"；
   - 点击"确认执行"后状态变为"已执行"，并出现"撤销"按钮；
   - 第二次确认同一动作时触发 409 冲突横幅；
   - 用户事实页可修改、否认、删除一条事实。
