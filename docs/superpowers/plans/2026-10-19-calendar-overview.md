# 日历概览与事项卡片调整

用户已通过页面批注明确月视图只标记有安排的日期、点击填写当天重要事项，以及卡片时间、阴影和日期分隔要求。

1. `lib/calendarDays.ts` 计算当前日期范围中有安排的天；只按实际时间块标色，跨午夜时结束点不多标一天。
2. `composables/useDayNotes.ts` 逐日期保存便笺到当前浏览器；保存失败显示错误，刷新恢复，支持跨标签页更新。便笺不调用排程 API。
3. `CalendarPage.vue` 月格只显示日期、安排底色、便笺标记；日期按钮打开可编辑对话框，保存/清空后更新。日/周视图保留具体安排。
4. `workspace.css` 统一起止字号并加入横线，移除卡片高光阴影，事件贴齐日期列边缘；日期列加竖向边界。
5. Vitest 验证日期归属；Playwright 验证月视图无事件详情、便笺持久化/清空/失败、卡片字体与分隔、三视图切换；完成类型检查和构建，保留已有未提交调整。

范围：重要事项只保存在当前浏览器，清理站点数据会移除便笺；本轮不变更后端日程与数据库。
