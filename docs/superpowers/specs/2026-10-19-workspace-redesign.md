# 学习工作台改版

用户选择：暖白底、墨蓝文字、青绿色主操作的清爽学习工作台。

基线提交：9eb7d74；备份分支：codex/frontend-before-redesign-20261019。
原 8080 打包版保留，5174 为连接相同后端的开发预览。

## 设计和范围
- 保留三主导航及设置内的导入、偏好入口，缩减标题和技术说明。
- 全站统一卡片、输入、按钮、留白、焦点和窄屏布局。
- AI 流程显式展示输入、核对、保存；输入变化或日程版本变化后禁止确认旧建议；保存中禁止再次生成。
- 输入框恢复原生选字，语音由独立按钮启动；生成后在窄屏滚到预览。
- 任务支持关键词、状态、截止/优先级排序；区分首次使用、筛选无结果；窄屏表格改卡片。
- 不变更后端契约、人工确认、幂等与撤销语义，不虚构导入识别能力。

## 外部设计讨论
使用已配置的 DeepSeek API，只发送界面结构与设计问题，没有发送用户日程或凭据。
模型目录返回 deepseek-flash / deepseek-v4-pro；尝试日期型号未被接受。
实际讨论模型：deepseek-flash。采纳导航密度、AI建议生命周期、准确空态和独立语音入口建议。

## 执行计划与验收
1. App.vue + workspace.css：全局导航及响应式主题；检查 390/444/1440 宽度。
2. AiPage.vue + useVoiceInput.ts：状态与防误操作；验收输入变更、保存、失败及语音。
3. TasksPage.vue + lib/tasks.ts：搜索排序与空态；单测排序/过滤，浏览器检查卡片。
4. 日历、导入、偏好统一布局，保留原业务操作。
5. build、Vitest、隔离数据库的 Playwright 回归。测试端口与开发预览分离。
